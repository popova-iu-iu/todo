# База знаний — описание проекта

Личная база знаний «как Obsidian, только проще и красивее». Заметки — не Markdown, а **красивые HTML-страницы, собранные из блоков** по шаблонам. Главный принцип — **всё должно быть просто**: никаких спецсимволов (`/`, `[[ ]]`), минимум кнопок, всё появляется только когда нужно.

Рядом с этим файлом лежит `prototype.html` — кликабельный прототип мобильной версии. Это эталон внешнего вида и поведения: открыть в браузере и повторить.

---

## 1. Платформа и порядок работы

- **Сейчас: только iPhone.** Mac появится примерно через месяц.
- **Этап 1 — веб-приложение (PWA), которое ставится на экран «Домой»** через Safari → «Поделиться» → «На экран „Домой“». Открывается на весь экран, работает без интернета, данные хранятся на устройстве.
  - Хостинг кода — бесплатно на GitLab Pages (там только код, заметок там нет).
- **Этап 2 (когда будет Mac):** тот же код упаковать в Tauri — настоящая программа для Mac (и при желании для iPhone). Заметки — обычные `.html`-файлы в папке, как в Obsidian.
- Код писать так, чтобы слой хранения можно было заменить: сейчас IndexedDB, потом файлы на диске.

## 2. Зашифрованный бэкап в GitLab

- Пароль задаётся один раз; ключ получается из пароля (Argon2id или PBKDF2), пароль никуда не отправляется.
- Каждая заметка шифруется на устройстве (AES-256-GCM, WebCrypto). Имена файлов тоже шифруются/хешируются.
- Зашифрованные файлы отправляются через GitLab API в **приватный** репозиторий (Personal Access Token). Git даёт историю версий.
- Автокопирование после изменений + кнопка «Сделать копию сейчас» + «Восстановить из копии».
- Тот же репозиторий служит синхронизацией между устройствами (iPhone ↔ Mac).
- Предупредить пользователя: без пароля восстановить нельзя → предложить ключ восстановления.

## 3. Структура программы (3 экрана + настройки)

1. **Главная = плитки шаблонов.** Сверху заголовок «Мои заметки», шестерёнка (настройки), поиск. Ниже сетка 2 колонки: плитка = картинка-миниатюра шаблона + название во множественном числе + число заметок («4 заметки» / «Пока пусто»). Последняя плитка — «+ Новый шаблон».
   - Порядок: Путешествия, Книги, Рецепты, Люди, Фильмы, Идеи, Проекты, Конспекты, Дневник, [свои шаблоны], Разное.
   - Поиск по всем заметкам → список результатов с названием полки.
2. **Экран шаблона** (нажали на плитку): обложка шаблона сверху, название, число заметок, большая кнопка «+ Новое путешествие / Новая книга / …», ниже **список заметок вниз** (название + дата, без картинок), новые сверху.
3. **Заметка:** обложка, текст и блоки. Кнопка «Назад» возвращает туда, откуда пришли.
4. **Настройки** (шестерёнка): бэкап (статус, «Сделать копию сейчас», автокопирование, шифрование, GitLab, устройства), «Карта связей», «Недавно удалённое» (хранится 30 дней), «Восстановить из копии».

**Не делать:** разделы/подразделы/папки (пробовали — сложно), сворачивающиеся категории, нижние вкладки, отдельную чёрную кнопку «Новая заметка», «Недавние».

## 4. Редактор заметки

- **Нет режима «Изменить»:** нажал на текст — пишешь (как Apple Notes). Сохраняется само.
- **Нет панели инструментов.** При выделении текста появляется маленькое меню из 3 действий: **Жирный · Заголовок · Связать**.
- **«Связать»** — выбор заметки из списка с поиском (или «Создать новую заметку»), выделенное слово становится ссылкой. Ссылки двусторонние: внизу заметки строка «Связано» с обратными ссылками.
- **Кнопка «+»** (круглая, чёрная, справа внизу) → шторка с 8 блоками: Фото, Заголовок, Список дел, Выноска, Карточки, Галерея, Цитата, Разделитель. Блок вставляется оформленным, текст в нём редактируется.
- **Удаление блока — свайп влево:** блок отъезжает, справа появляется красная кнопка «Удалить» с корзиной → блок удаляется, внизу 6 секунд «Вернуть», плюс попадает в «Недавно удалённое». Название заметки так не удаляется. Вертикальный жест — прокрутка, не свайп. На iPhone использовать touch-события (pointer-события в Safari ненадёжны), кнопку «Удалить» держать вне contenteditable.
- **Не делать:** корректор/ластик, кнопку «⋯» на блоке, крестик — всё пробовали и отказались.
- Безопасность: при сохранении очищать HTML (DOMPurify), чтобы вставленный код не выполнялся.

## 5. Шаблоны (главная фишка — пользователю очень нравятся)

Каждый шаблон создаёт **готовую страницу**: своя обложка-иллюстрация + набор блоков с серыми подсказками (placeholder), которые исчезают при вводе.

| Шаблон | Полка | Что внутри |
|---|---|---|
| Путешествие | Путешествия | обложка с горами; выноска «Не забыть»; карточки мест; список «Что взять»; фото |
| Книга | Книги | обложка с книгой; автор/оценка; главная мысль (выноска); цитата; «Что применю» |
| Рецепт | Рецепты | карточки «Время» и «Порции»; продукты (галочки); шаги; совет; фото блюда |
| Человек | Люди | силуэт; карточки «Телефон», «День рождения»; «Важно помнить»; «О чём говорили»; «Хочу сделать» |
| Фильм | Фильмы | тёмная обложка с плёнкой; «Оценка», «С кем смотрела»; впечатления; цитата |
| Идея | Идеи | лампочка; суть (выноска); «Зачем»; следующий шаг; связанные мысли |
| Проект | Проекты | цель; карточки «Начало» / «Готово к»; задачи; заметки |
| Конспект | Конспекты | лист в линейку; источник; «Главное»; «Подробно»; вопросы |
| Дневник | Дневник | название = сегодняшняя дата; настроение (5 вариантов); «За что благодарна»; мысли |
| Чистый лист | Разное | только название и текст |

**Свой шаблон:** плитка «+ Новый шаблон» → название + цвет обложки → открывается пустая страница в «режиме шаблона» (подсказка сверху), собираешь из блоков, вписываешь подсказки → «Сохранить шаблон». Появляется новая плитка на главной. Шаблоны хранятся вместе с заметками и попадают в бэкап.

## 6. Внешний вид

- Шрифты: **Manrope** (заголовки, 700–800), **Inter** (текст). Кириллица.
- Цвета: фон `#F4F5F7`, карточки `#FFFFFF`, текст `#17191C`, вторичный `#5B6068`, линии `#E3E5E9`.
  Акцент шалфей `#2E6B52` / светлый `#DCEBE3`; лаванда `#3E4594` / `#E4E6F5`; персик `#8A4B1E` / `#FBF1E7`.
- Скругления 14–22 px, мягкие тени, кнопки не меньше 44 px.
- Иконки — тонкие линейные SVG, без эмодзи (кроме настроения в дневнике).

## 7. Ещё не решено

- Фото: из галереи / камеры, обрезка, подписи.
- Первый запуск: пароль, ключ восстановления, подключение GitLab.
- Тёмная тема.
- Перестановка блоков местами (вероятно, долгое нажатие и перетаскивание).
- Карта связей — нужна ли.

## 8. С чего начать

1. Каркас PWA (manifest, service worker, офлайн), хранение в IndexedDB.
2. Главная с плитками → экран шаблона → заметка, навигация «Назад».
3. Редактор: contenteditable, меню выделения, «+» с блоками, свайп-удаление с «Вернуть».
4. Все 10 шаблонов + свой шаблон.
5. Шифрование и бэкап/восстановление через GitLab API.
6. Публикация на GitLab Pages и установка на iPhone.
