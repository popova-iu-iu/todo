# Электронная музыка с нуля

Личный интерактивный учебник: как писать электронную музыку в **Ableton Live** с контроллером **Arturia MiniLab 3** и рекордером **Zoom H1essential**. Всё нарисовано и всё можно послушать: барабанные сетки, пиано-роллы, клавиатура, синтезатор и эффекты прямо на странице.

Это приложение для iPhone: ставится на экран «Домой», открывается на весь экран и **работает без интернета** — звуковая библиотека и шрифты лежат в самом приложении.

## Установка на iPhone

1. Откройте адрес приложения в **Safari** (адрес — в панели Vercel, проект `todo-shey`).
2. «Поделиться» → **«На экран „Домой“»**.
3. Значок «Музыка» появится на экране. После первого открытия курс работает и без интернета.

Звук играет, даже если на iPhone включён беззвучный режим (iOS 16.4 и новее).

## Что внутри

- **Путь: от лупа до трека** — 11 глав: барабаны, бас, аккорды, синтез, сэмплы, обработка, автоматизация, аранжировка, сведение, мастеринг, трек любого жанра.
- **Жанры** — карта жанров и примеры: house, deep house, techno, trance, drum & bass, dubstep и другие.
- **Ableton Live, MiniLab 3, Zoom H1essential** — где что находится и как этим пользоваться.
- **Теория** — ноты, лады, аккорды, ритм.

## Публикация

Репозиторий подключён к **Vercel**: после каждого изменения в `main` выкладывается новая версия. Настройки сборки — в [`vercel.json`](vercel.json).

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # сборка + проверки в браузере с эмуляцией iPhone
npm run build    # сборка в dist/
```

| Где | Что |
|---|---|
| `public/js/` | сам курс: звуковой движок (`audio.js`), рисунки (`draw.js`), страницы (`content/`), лаборатории (`labs.js`) |
| `index.html` | оформление курса и подключение скриптов |
| `src/` | шрифты и всё, что делает из курса приложение: работа без интернета, звук в беззвучном режиме |
| `vite.config.ts` | сборка, значок и манифест приложения; Tone.js берётся из npm и кладётся в `vendor/` |
